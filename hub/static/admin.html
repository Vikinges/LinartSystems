Upload service bundle (ZIP)

ZIP can include hub-service.json + Dockerfile. If Dockerfile is missing but index.html is found, hub will build a static nginx container automatically. 
hub-service.json example:
{
  "name": "crm",
  "id": "crm",
  "prefix": "/crm",
  "internalPort": 3000,
  "displayName": "Customer portal",
  "description": "Service uploaded as ZIP",
  "env": { "NODE_ENV": "production" }
}
Form fields override values inside hub-service.json. Only superadmin can upload and run services.
